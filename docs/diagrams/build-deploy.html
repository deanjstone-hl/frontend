frontend build and release

Nothing deploys to a host. A version is a tag on the promoted commit, cut only when the owner promotes.

Sources: docs/deploy-branch.md, .github/workflows/test.yml, design.yml, release.yml, scripts/check.sh. With nothing releasable the run ends green with no test and no version. The release commits nothing, so deploy stays a fast-forward of main. Roll back with a revert on main plus a promotion; never force-push deploy.
