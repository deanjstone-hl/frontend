Architecture

frontend architecture

A registry of files, not a package: sources and themes build into plain output on main, and each consumer pulls items with the shadcn CLI.

Sources: README.md (Structure, Consumers, Consuming this registry), scripts/check.sh, scripts/theme/build.mjs. No server and no publish step: the shadcn CLI reads registry.json straight from GitHub and copies files into the consumer. The consumer list is in the README and is checked by the primitives-usage audit.
